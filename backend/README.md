# 🚀 FastAPI Project

A minimal FastAPI backend setup.

## 🛠️ Setup

### 1. Create Virtual Environment

```bash
python -m venv venv
.venv\Scripts\Activate.ps1  # Windows: venv\Scripts\activate
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the App

```bash
fastapi dev main.py
```

Open in browser: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
